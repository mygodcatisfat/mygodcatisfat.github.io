使用說明

本工具完全在瀏覽器內運算，圖片不會上傳到任何伺服器，可離線使用。適合 Logo、圖示、線稿、截圖等色塊分明的圖片；照片類效果有限，容易產生大量路徑與較大檔案。

操作步驟

  1. 上傳圖片：點擊上傳區塊選擇檔案，或直接拖曳圖片進去，支援 PNG / JPG / GIF / BMP / WEBP / HEIC。
  2. 選擇預設集：依圖片類型挑一組最接近的預設（Logo / 線稿 / 截圖 / 照片），系統會自動帶入建議參數。
  3. 視需要微調參數：每項下方都有說明文字，滑桿調整後畫面不會自動更新，需再次按「轉換」。
  4. 輸入檔案名稱（可選）：預設會用目前時間產生檔名，也可以自行修改。
  5. 按下「轉換為 SVG」：畫面會顯示即時進度，完成後右側會出現向量化結果與統計資訊。
  6. 下載或複製：滿意結果後可下載 .svg 檔案，或直接複製 SVG 原始碼貼到其他地方使用。

常見狀況

  • SVG 檔案比原圖還大：通常代表顏色數太多或圖片雜訊太多，可嘗試降低顏色數量、提高忽略雜點的數值。
  • 出現大量白色斑點：這是照片紋理被誤判成雜訊色塊造成的，請提高「模糊去雜訊」與「模糊敏感度」再重新轉換。
  • 手機轉換大圖：為避免記憶體不足導致分頁被系統關閉，超過門檻的圖片會自動等比例縮小後再處理，並於結果區標示。
  • HEIC 無法開啟：HEIC 是 iPhone 的預設照片格式，只有 Safari 等部分瀏覽器能直接解碼。若出現提示，請改用 Safari，或先把照片轉存成 JPG / PNG 再上傳。

圖片被簡化成幾種顏色來描繪。數字越大越接近原圖，但檔案也越大。Logo 用 4～8，照片建議 20 以上。
直線邊緣容許誤差(ltres)。數字越大邊緣被拉直、簡化越多；設 0 表示盡量貼合原始像素邊緣。
弧線、圓角容許誤差(qtres)。數字越大曲線被簡化越多，點數變少、更平滑但較失真。
面積小於這個像素數的雜點會被刪除(pathomit)，用來清掉雜訊；數字太大可能誤刪小細節（如文字）。
轉換前先模糊化(blurradius)，減少雜訊與鋸齒，代價是細節變糊。上限 5 為函式庫硬性限制。
判斷像素算不算雜訊的門檻(blurdelta)，只在模糊去雜訊開啟時有效。出現大量白色斑點時請調高此值。
保持直角
保留圖片中的 90 度直角轉彎，適合截圖、UI、建築線稿；照片、手繪圖建議關閉。
只放大輸出座標值(scale)，不影響清晰度。除非有特殊需求，一般保持 1x 即可。
