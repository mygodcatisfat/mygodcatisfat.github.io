功能說明

把圖片拖進來，AI 會自動辨識主體並移除背景。如果結果不完美，可以用內建的修補工具把它調到滿意為止——所有修補都是即時的，不需要重跑 AI。全部運算都在你的瀏覽器裡完成，圖片不會上傳到任何伺服器。

事前：框出主體範圍

AI 模型會把圖片縮放到固定尺寸再辨識。先把主體框起來、去掉無關的邊緣，主體在模型眼中的佔比就會變大，細節通常會更準確。不想框也可以直接按「使用完整圖片」。

事後：修補工具

  • 保留筆刷：AI 把不該去掉的地方吃掉了（手指、髮尾、細桿子），塗回來。
  • 移除筆刷：背景殘留沒清乾淨，塗掉。
  • 魔術棒：點一下就處理整塊顏色相近的區域，比慢慢塗快得多。容差調高選取範圍越大。
  • 勾選「顯示被移除的區域」會用紫色標示哪些地方會被去掉，比較容易看出哪裡切錯。
  • 「按住看原圖」可以隨時比對原始畫面。

邊緣調整

  • 遮罩門檻：控制半透明區域要算前景還是背景。頭髮毛邊被砍光時往下調。
  • 邊緣柔度：門檻的過渡範圍，越大邊緣越軟。
  • 收縮 / 擴張：邊緣留了一圈原本的背景色（白邊、綠邊）時，往負向調１～３通常就能消掉。
  • 羽化：整體模糊邊緣，讓它跟新背景融合得更自然。

輸出樣式

可以換成純色或漸層背景、加上白色描邊做出貼紙感、或加陰影。這些都只影響輸出外觀，不會動到去背本身。

鍵盤快捷鍵

  • [ / ]　縮小 / 放大筆刷
  • Ctrl+Z　復原　　Ctrl+Y　重做

使用限制

  • 需要網路連線。AI 模型（數十 MB）在頁面開啟時就會於背景開始下載，剛好和你挑圖、框選主體的時間重疊，所以通常輪到你按「開始去背」時它已經就緒。
  • 模型不會被保留在本機，每次重新開啟頁面都會重新下載一次（這是函式庫在 Web Worker 內自行抓取造成的，頁面端無法攔截快取）。所以同一批圖片建議在同一個分頁裡連續處理完，不要中途重整。
  • 修補作業在縮放後的畫面上進行（長邊上限 1600px），匯出時會還原成原始解析度。極細的髮絲若有些微軟化屬正常現象。
  • 建議使用 Chrome / Edge 等現代瀏覽器。
