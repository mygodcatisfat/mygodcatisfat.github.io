使用說明

1. Gemini API Key
  • 前往 Google AI Studio 免費申請 API Key。
  • 貼上後可按「驗證」確認 Key 是否有效，Key 會存在瀏覽器 localStorage，換裝置需重新輸入。
  • 此工具純前端運作，Key 直接從你的瀏覽器呼叫 Google 官方 API，不會經過任何第三方伺服器；請勿把此檔案分享給他人使用，以免 Key 外流。
2. 上傳與分析
  • 支援單一檔案（如 .html）或多個檔案（如 Python 專案的多個 .py）。
  • 單一檔案內容超過 2 萬字或全部檔案總計超過 10 萬字時，會自動截斷以避免超出模型限制。
  • 按下「分析程式碼」後會呼叫 Gemini 模型，產出 100 字內說明、3 個英文 hashtag 與 3 個中文 hashtag。
3. 分析歷程
  • 每次分析結果會累加到「分析歷程」清單，不會覆蓋先前的結果。
  • 可點擊每筆結果中的說明文字或 hashtag 直接複製到剪貼簿。
  • 可刪除單筆歷程，或使用「清空歷程」一次清除全部紀錄。
